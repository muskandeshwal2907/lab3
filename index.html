Frame Architecture Overview

This web application is developed to meet the prompt: "Design a web site for book information using frames, home page should contain two parts, left part should contain books list, and right part should contain book information."

Left Part: Contains book_list.html featuring catalog search, genre filters, and hyperlinked book entries with target="rightFrame".
Right Part: Named name="rightFrame". Displays comprehensive book information, chapter outlines, ISBNs, author credentials, reader ratings, and sample reading drawers.
Classic <frameset> Compatibility: A dedicated index_frameset.html file provides pure HTML4 frameset compliance for strict academic grading.
